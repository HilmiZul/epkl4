# e-PKL

Aplikasi pemetaan, jurnal dan rapor PKL untuk Kepsek, Wakasek, Jurusan, Guru Pembimbing dan TU.

Original proyek (versi awal) ini sudah diarsipkan, lihat [dsini](https://github.com/hilmizul/epkl).

# Ingredients

- [Node.js](https://nodejs.org) or [Bun](https://bun.dev) or [Deno](https://deno.com)
- [Vue](https://vuejs.org)
- [Nuxt](https://nuxt.com)

# Setup

```bash
bun install
```
or
```bash
npm install
```

# Development Server

```bash
bun run dev
```
or
```bash
npm run dev
```
or
```bash
deno task dev
```

# Production

```bash
bun run build
```
or
```bash
npm run build
```
